# 特征引导重拓扑减面设计方案

## 1. 文档目的

本文档记录 LODify 后续扩展“特征引导重拓扑减面”的技术方案。目标是把参考插件 Loop Resample 的局部边流重采样能力，扩展为面向整个模型的、可以自动分析和分区的减面工作流。

本文档是设计和实施依据，不代表功能已经实现。后续开发应按照阶段逐步落地，每个阶段都应保留可用的回退路径。

参考项目：

- LODify：当前仓库
- Loop Resample：`C:/Users/TSUNE/Desktop/add-on-loop-resample-v1.0.3`

参考插件的核心模块：

- `core/regions.py`：捕获选中边链之间的相邻表面区域
- `core/planner.py`：规划两条边界之间的单调条带连接
- `core/geometry.py`：检测退化面、法线偏差和几何交叉
- `core/rebuild.py`：删除旧面并重建边、面和三角扇
- `core/attributes.py`：恢复 UV、Seam、Sharp、材质和点/边属性
- `core/session.py`：冻结源网格，支持多次预览、提交和取消
- `ui/interactive.py`：编辑模式交互式调整采样数量和形状

## 2. 目标和非目标

### 2.1 目标

1. 自动找出最影响模型外形的特征边链。
2. 把特征边链组织为可以安全重建的边界和面带。
3. 在平坦、低曲率或低屏幕占比区域降低采样密度。
4. 在轮廓、硬边、高曲率和重要接缝附近保留更多几何细节。
5. 使用 Loop Resample 的条带规划和属性恢复逻辑重建可控的局部拓扑。
6. 与 LODify 现有的相机屏幕占比 LOD 结合。
7. 对无法安全自动处理的区域保留原网格或回退到现有 Decimate。
8. 在预览、失败、取消和提交过程中保持原始网格可恢复。

### 2.2 非目标

第一阶段不承诺：

- 任意复杂模型都能生成完整、干净的全四边面拓扑。
- 自动修复所有非流形、重叠面、严重自交和坏法线。
- 替代 Blender 的 QuadriFlow、Voxel Remesh 或专业自动重拓扑工具。
- 在没有额外设计的情况下保持 Shape Keys、骨骼绑定和所有修改器结果。
- 对雕刻高模直接生成生产级动画拓扑。

本功能的初始定位是“特征引导的保形减面和局部重拓扑”，不是通用自动拓扑器。

## 3. 产品形态

建议提供三个层级的工作模式。

### 3.1 分析模式

只计算特征分数并显示候选边链，不修改网格。

用户可以查看：

- 高曲率边
- 硬边和 Sharp 边
- UV 或材质边界
- 当前相机下的轮廓边
- 预计会被保护的区域
- 预计可以减面的区域

分析模式是后续所有自动操作的输入，也用于调试特征检测器。

### 3.2 引导式减面模式

自动选取并保护主要边链，然后对可处理的面带降低采样数。不能被条带重建覆盖的区域，使用加权 Decimate 或保持原状。

这是第一版最重要的生产模式，目标是稳定减面和保持轮廓。

### 3.3 全模型重拓扑模式

尝试让更多区域都进入条带重建流程，生成更规整的局部四边面网络。该模式计算量更高，失败概率更高，应作为实验功能逐步开放。

## 4. 总体处理流程

```text
读取对象和评估网格
        |
        v
预检查：模式、修改器、非流形、UV、Shape Keys、绑定
        |
        v
计算边重要性分数
        |
        v
提取、连接、清理候选特征边链
        |
        v
根据候选边链划分可处理面带
        |
        v
为每个面带计算目标采样数
        |
        v
冻结源网格并建立重建计划
        |
        v
Loop Resample 条带规划和重建
        |
        +---- 成功 ----> 属性恢复、质量验证、预览/提交
        |
        +---- 失败 ----> 标记区域，回退到 Decimate 或保持原状
        |
        v
生成结果报告和统计信息
```

整个流程必须以源网格快照为基础。不能在同一轮处理中直接读取上一个局部修改的结果再继续猜测其他区域，否则区域边界和索引会不断漂移，最终难以恢复和验证。

## 5. 特征边重要性模型

### 5.1 两种分析坐标系

功能应支持两种特征分析模式：

#### 物体形状模式

不依赖相机，适合生成可复用的模型 LOD。主要关注：

- 边界和孔洞
- 二面角
- 曲率变化
- Sharp、Crease 和用户标记
- UV、材质和法线分界

#### 相机 LOD 模式

针对当前 LOD 相机，适合运行时场景优化。除物体形状因素外，还关注：

- 当前屏幕轮廓
- 屏幕投影长度
- 屏幕像素覆盖率
- 轮廓附近的法线变化
- 物体距离和遮挡情况

两种模式的特征权重不能混用。相机模式的结果不能默认当作通用模型拓扑保存。

### 5.2 单边评分

建议把每条边的总分限制在 `[0, 1]`，便于 UI 显示和后续阈值调整：

```text
score(e) = clamp(
    w_boundary * boundary(e)
  + w_dihedral * dihedral(e)
  + w_curvature * curvature(e)
  + w_mark * marked(e)
  + w_uv * uv_boundary(e)
  + w_material * material_boundary(e)
  + w_silhouette * silhouette(e)
  + w_density * density_change(e),
  0, 1
)
```

建议的初始优先级：

| 特征 | 初始优先级 | 说明 |
|---|---:|---|
| 非流形、开放边界 | 最高 | 默认保护，除非用户明确允许处理 |
| Sharp、Crease、用户标记 | 很高 | 用户已有意图，应优先保留 |
| 大二面角 | 高 | 通常表示硬表面折角或明显形状变化 |
| 相机轮廓 | 高 | 只在相机 LOD 模式中增加权重 |
| 高曲率变化 | 中高 | 对有机模型有用，需要平滑去噪 |
| UV 边界 | 中 | 用于避免纹理拉伸和跨岛重建 |
| 材质边界 | 中 | 避免面带跨越材质区域 |
| 密度变化 | 中低 | 用于寻找过密区域，不应单独决定保护 |

不应只按照边的二面角排序。高模三角网格、扫描网格和噪声表面会产生大量短而不连续的高分边，需要进行空间和拓扑上的清理。

### 5.3 特征分数平滑

边分数应在边图上做有限范围的平滑，但必须保留硬边和边界的硬约束：

```text
smoothed(e) = alpha * score(e)
            + (1 - alpha) * average(neighbor_scores(e))
```

建议：

- Sharp、Crease、非流形和边界不参与降权。
- 平滑只进行 1 到 3 轮。
- 极短边和孤立高分边需要合并或删除。
- 低于阈值的连续链不进入重拓扑候选集。

## 6. 特征边链提取

### 6.1 候选边筛选

从 BMesh 读取边和相邻面，过滤以下情况：

- 隐藏边或隐藏对象
- 被标记为不可处理的边
- 退化边或长度接近零的边
- 受 Shape Keys 或特殊数据层影响且当前策略不支持的边
- 明确属于保护区域的边

默认保护：

- 非流形边
- 开放边界
- 用户标记的 Sharp 和 Crease
- UV 边界
- 材质边界

是否保护 Seam 应提供单独选项，因为某些模型会把 Seam 大量铺在不影响形状的区域。

### 6.2 路径追踪

高分边集合需要转为有序路径，不能只保留一个无序集合。路径追踪规则建议如下：

1. 从局部极值边或边界端点开始。
2. 沿相邻边选择方向变化最小、分数较高的下一条边。
3. 对四边面网格优先沿相对边方向继续追踪。
4. 遇到分叉时停止当前路径并记录分叉点。
5. 遇到环时记录闭合路径和切口位置。
6. 对路径进行折线简化，但不能跨越硬边或 UV 边界。

建议把路径分为：

- `OPEN_PATH`：有两个端点的边链
- `CLOSED_LOOP`：闭合边环
- `BOUNDARY_PATH`：开放边界的一部分
- `FEATURE_PATH`：由曲率、Sharp 或轮廓产生的内部特征链
- `PROTECTED_PATH`：只允许作为边界，不允许降低采样数

### 6.3 路径质量

每条路径都需要记录：

```text
path_id
vertex_indices
edge_indices
closed
feature_score
protected
source_type
length
average_curvature
screen_coverage
uv_crossings
branch_points
```

短路径、分叉过多的路径和无法匹配邻接区域的路径应只用于显示，不直接进入重建。

## 7. 面带识别和区域划分

参考插件的 `capture_adjacent_strips()` 是这一阶段的基础，但自动模式需要额外的候选路径验证。

### 7.1 合法面带条件

一个面带至少应满足：

- 存在两条有序边界路径，或一条路径加上可识别的固定边界。
- 中间面集合连通。
- 面集合没有被其他保护路径不明确地穿过。
- 面带能被完整遍历，不能存在未解释的洞或分叉。
- 两侧路径的方向和端点能够建立一致的对应关系。
- 重建后的面不会产生重复顶点、零面积面或明显自交。

### 7.2 路径配对

候选路径之间不能只按空间距离配对。建议综合：

- 面邻接关系
- 路径之间的最短表面距离
- 路径长度比例
- 原始网格中的跨带边数量
- 共同的 UV 和材质区域
- 原始法线和面中心采样

如果路径之间没有明确的面带关系，则拒绝配对，不使用距离猜测。

### 7.3 区域类型

沿用参考插件的区域分类思路：

- `STRIP`：两条路径之间的普通面带
- `CAPPED_STRIP`：一端或两端带有封口特征的面带
- `FAN`：围绕一个极点的三角扇
- `NGON_CAP`：由闭合边界包围的 Ngon 区域
- `OPEN_NGON_CAP`：开放边界和固定链组成的封口
- `POLE_NGON`：围绕一个极点的单面区域
- `UNSUPPORTED`：无法安全解释的区域

`UNSUPPORTED` 必须保留原始面，并在结果报告中说明原因。

## 8. 目标密度和采样数

### 8.1 目标面数来源

目标密度可由三个来源组合：

1. 用户指定的全局目标比例。
2. LODify 当前屏幕占比计算出的对象级目标比例。
3. 区域级重要性权重。

建议先计算对象级目标比例，再对各个区域应用保护权重：

```text
region_ratio = clamp(
    object_ratio * (1 - reduction_bias(region_importance)),
    minimum_ratio,
    1.0
)
```

高重要性区域的 `region_ratio` 更接近 1，平坦且远离相机的区域可以进一步降低。

### 8.2 采样数约束

对于一条边链：

- 开放路径至少保留 2 个点。
- 闭合路径至少保留 3 个点。
- 重要特征点、Seam 交点和路径端点必须被固定到采样槽位。
- 相邻路径的采样数差距不能超过区域规划器可处理的范围。
- 不允许生成重复采样点或极短边。

采样数分配应优先满足硬约束，再在剩余槽位中按曲率和弧长分配。

### 8.3 局部密度连续性

相邻面带之间的目标密度不能突然跳变。建议限制：

```text
abs(count(region_a) - count(region_b)) <= max(1, round(0.25 * shared_count))
```

超过限制时，应延迟处理、合并区域，或使用过渡带，而不是分别重建两个相邻区域。

## 9. Loop Resample 算法的复用范围

### 9.1 可以直接复用的部分

- `ResampleSession` 的源网格冻结和取消恢复机制。
- `capture_adjacent_strips()` 的相邻区域捕获。
- `build_ordered_strip_plan()` 的条带动态规划。
- `validate_ordered_strip_plan()` 的退化检查。
- `diagnose_ordered_strip_geometry()` 的交叉诊断。
- `apply_ordered_strip_plan()` 的面重建。
- `rebuild_triangle_fan()` 和 `rebuild_ngon_cap()` 的特殊区域处理。
- `core/attributes.py` 中的 Seam、Sharp、UV、材质和点属性转移。
- 参考插件的失败后保持上一状态的交互策略。

### 9.2 必须新增或改造的部分

- 自动特征评分。
- 候选边链提取和路径简化。
- 全模型区域覆盖和区域冲突管理。
- 区域级目标采样数分配。
- 多区域同一源快照上的批量重建。
- LODify 的相机和屏幕占比输入适配。
- 对已有修改器、实例源和隐藏对象的处理。
- 结果质量统计和失败区域报告。

### 9.3 不能直接假设的能力

参考插件能够重采样用户选中的合法路径，不代表自动检测出的任意边集合都能进入规划器。自动路径必须先满足顺序、闭合状态、区域覆盖和属性边界条件。

## 10. 全模型批处理策略

### 10.1 源快照

一次处理开始时：

1. 把目标对象转换为可处理的 BMesh 快照。
2. 记录原始网格索引、顶点坐标、面法线、UV 和属性。
3. 记录对象变换和需要恢复的修改器状态。
4. 在整个计划执行期间禁止依赖上一次局部重建后的索引。

### 10.2 区域冲突

多个区域可能共享边或顶点。建议建立冲突图：

- 区域共享待删除面时，不能并行独立提交。
- 区域共享保护路径时，必须统一采样数和槽位。
- 区域存在重叠面时，优先保留重要性更高的区域，低优先级区域回退。
- 共享区域的计划失败时，相关邻接区域一起回退，避免留下裂缝。

### 10.3 提交顺序

建议顺序：

1. 分析和建立所有区域计划。
2. 验证全部计划和冲突图。
3. 在临时 BMesh 中删除旧面。
4. 重建所有路径和区域面。
5. 恢复 UV、Seam、Sharp、材质和选择状态。
6. 进行全局质量检查。
7. 通过检查后写回活动网格，否则丢弃临时结果。

不能在计划尚未完整验证时直接写回用户网格。

## 11. 减面算法改进方向

### 11.1 现有 LODify 的定位

当前 LODify 已有：

- 基于相机屏幕占比的对象级比例计算。
- Decimate 修改器模式。
- Geometry Nodes 顶点合并模式。
- 最小面数和最小比例保护。
- Setup、Update、Reset 和 Apply 流程。

这些流程应保留，新的特征引导系统作为更细粒度的控制层加入。

### 11.2 Decimate 保护策略

建议新增：

- 保护边界和非流形区域。
- 保护 Sharp、Crease 和用户确认的主要边链。
- 保护相机轮廓附近的边和顶点。
- 在 UV 或材质边界处降低跨界折叠概率。
- 支持对象级和区域级最小保留比例。
- 应用前后统计真实面数，而不是只记录目标比例。

如果使用 Decimate 的顶点组或边界选项，必须验证实际版本中的行为。软权重不能被当作绝对不可删除的硬约束，重要特征仍需要应用后检查。

### 11.3 Geometry Nodes 方案重新定位

当前 Geometry Nodes 方案主要使用 Merge by Distance 和角度选择逻辑。它适合快速、非破坏性的顶点合并实验，但不应直接称为“高质量重拓扑”。后续可以：

- 将名称改为“距离合并减面”或类似描述。
- 保留它作为快速预览和低风险批处理选项。
- 将特征保护结果转为选择字段或权重字段。
- 对合并半径设置对象尺度和屏幕占比相关的上限。
- 在应用前提示它不能保证四边面流和 UV 质量。

### 11.4 两段式减面

推荐的默认生产流程：

```text
特征分析
    |
    v
对高重要性区域做引导式条带重采样
    |
    v
对剩余低重要性区域执行加权 Decimate
    |
    v
全局几何和属性检查
```

这可以兼顾轮廓、硬边和整体面数。条带重采样失败的区域不应阻塞整个对象处理。

## 12. 属性和修改器兼容性

### 12.1 必须优先支持

- 顶点坐标
- 面法线和法线方向
- 面材质索引
- UV 层
- Seam
- Sharp
- 平滑面标记
- 普通顶点组和自定义属性

### 12.2 需要明确限制或单独适配

- Shape Keys
- Armature 绑定和权重
- 面角自定义法线
- 多 UV 层
- Geometry Nodes 产生的实例几何
- 粒子系统和实例源对象
- 依赖原始顶点索引的外部数据
- 非应用状态的修改器栈

默认建议：对存在 Shape Keys 的对象先拒绝自动重拓扑，只允许使用非破坏性 LOD 或用户明确确认的应用流程。骨骼权重可以作为后续阶段的顶点属性转移问题处理。

## 13. 失败处理和回退

每个区域都应返回结构化结果：

```text
region_id
status: SUCCESS | FALLBACK_DECIMATE | PRESERVE | ERROR
reason_code
source_face_count
target_face_count
actual_face_count
max_normal_error
max_surface_error
uv_crossing_count
degenerate_face_count
```

建议的回退顺序：

1. 使用较保守的采样数重新规划。
2. 缩小区域到可验证的连续条带。
3. 对该区域保持原状。
4. 如果用户允许，对该区域执行受保护的 Decimate。
5. 报告失败原因，但不丢弃其他成功区域。

以下情况禁止静默提交：

- 面带计划未覆盖完整边界。
- 生成了零面积面或重复边。
- 发生明显法线翻转。
- UV 岛被无意跨接且用户选择了严格 UV 保护。
- 区域之间产生裂缝或重复面。
- 全局面数结果高于用户允许的上限。

## 14. 质量评估

### 14.1 几何误差

至少需要计算：

- 原网格到结果网格的近似 Hausdorff 距离。
- 结果到原网格的反向距离。
- 关键特征点的最大位移。
- 相机轮廓的屏幕像素偏差。
- 面法线变化和翻转数量。

第一版可以使用采样点和最近面近似，不必一开始实现完整高精度 Hausdorff 算法。

### 14.2 拓扑质量

检查：

- 零面积面数量。
- 极短边数量。
- 重复边和重复面。
- 非流形边变化。
- 孤立顶点。
- 面法线翻转。
- 自交候选数量。
- 三角形比例和极端长宽比。

### 14.3 属性质量

检查：

- UV 岛数量是否异常变化。
- Seam 是否断裂或产生孤立标记。
- Sharp 和 Crease 是否保留。
- 材质边界是否被错误跨越。
- 顶点组权重是否丢失。

## 15. UI 和交互建议

### 15.1 分析面板

建议新增“Feature Guided Retopo”面板，包含：

- 分析模式：物体形状 / 相机 LOD
- 特征阈值
- 轮廓保护开关
- Sharp、Crease、Seam、材质边界保护开关
- 候选边链显示
- 重新分析按钮
- 选择全部候选、取消低置信度候选

### 15.2 执行面板

包含：

- 目标减面比例或目标面数
- 最小保留比例
- 高重要性区域保护强度
- 允许局部回退到 Decimate
- 严格 UV 保护
- 预览、应用、重置

### 15.3 预览反馈

视图中应区分：

- 绿色：已验证并将执行重建的区域
- 黄色：候选区域，需要用户确认或质量不足
- 红色：失败并回退的区域
- 蓝色：保护边链

结果面板显示计划数量、成功区域、回退区域、原始面数、结果面数和最大误差。

参考插件的滚轮交互可以作为后续增强，用于局部调整采样数和曲线形状。第一版不必把全模型的所有区域绑定到同一个模态滚轮操作。

## 17. 分阶段实施计划

### 阶段 0：验证和基准

目标：不改变用户网格，只验证算法输入和性能。

- 建立测试模型集。
- 读取 BMesh 和属性层。
- 输出边评分和候选路径。
- 建立分析结果缓存。
- 记录耗时和内存。

交付标准：分析结果可视化，且不修改对象数据。

### 阶段 1：自动特征分析

- 实现边评分。
- 实现路径追踪和清理。
- 支持物体形状模式。
- 支持候选路径显示和用户确认。

交付标准：对四边面硬表面模型和简单有机模型能稳定找出主要边链。

### 阶段 2：单区域引导式重采样

- 接入 Loop Resample 的区域捕获和条带规划。
- 支持一个对象内的一个或少量面带。
- 保留 UV、Seam、Sharp、材质和撤销恢复。
- 失败时保持原区域。

交付标准：用户可以预览、取消和应用单区域结果，结果不会产生明显裂缝和退化面。

### 阶段 3：多区域批处理

- 建立区域冲突图。
- 在同一个源快照上规划多个面带。
- 实现共享边界和过渡密度。
- 增加区域级结果报告。

交付标准：多个不重叠区域可以一次性处理，邻接区域不会互相破坏。

### 阶段 4：接入相机 LOD

- 使用 LODify 的屏幕占比计算目标密度。
- 增加轮廓保护和相机模式。
- 对剩余区域使用加权 Decimate。
- 支持非破坏性预览和批量更新。

交付标准：相机远近变化会改变减面强度，主要轮廓和特征边保持稳定。

### 阶段 5：全模型实验模式

- 扩大区域覆盖率。
- 处理更多封口、极点和 Ngon 情况。
- 增加更完整的全局误差检查。
- 评估是否需要接入 QuadriFlow 或其他重拓扑后端。

交付标准：在明确支持的模型类别上提供可预测结果，并对不支持模型给出清晰报告。

## 18. 测试模型集

至少需要准备：

1. 规则四边面平面和盒体。
2. 带硬边、孔洞和倒角的机械零件。
3. 具有开口边界的圆柱和管道。
4. 闭合环形面带。
5. 三角扇和极点区域。
6. Ngon 封口模型。
7. UV 多岛和跨面带 Seam 模型。
8. 多材质模型。
9. 三角化扫描网格。
10. 高密度雕刻模型。
11. 非流形和自交错误模型。
12. 带 Shape Keys、顶点组和 Armature 的对象。
13. 使用 Geometry Nodes 实例化的场景。
14. 多对象、大规模场景。

每个模型应记录：原始顶点数、面数、边数、UV 层数、材质数、非流形边数和预期结果。

## 19. 性能要求

### 19.1 交互操作

- 分析阶段可以采用异步或分帧处理。
- UI 线程每帧处理时间应有预算，避免大场景完全冻结。
- 特征分数和候选路径应缓存，参数小幅调整时只重新计算受影响部分。

### 19.2 重建操作

- 先在临时 BMesh 中规划和验证。
- 不要在每个候选边或每个面上频繁调用 Blender 操作符。
- 优先使用 BMesh 和纯 Python 数据结构完成计算。
- 对相同对象的多次预览复用源快照、路径和区域捕获结果。
- 对高密度网格提供取消入口。

### 19.3 缓存失效

以下情况发生时必须丢弃缓存并重新分析：

- 用户修改了网格拓扑。
- 用户移动或删除了保护边链。
- 对象变换或相机变化影响了相机模式结果。
- 修改器栈发生变化。
- UV、材质或法线属性发生变化。

## 20. 风险和应对措施

| 风险 | 影响 | 应对 |
|---|---|---|
| 高曲率检测受噪声影响 | 产生大量错误特征链 | 分数平滑、最小长度和路径合并 |
| 候选边链无法组成面带 | 自动重建失败 | 先做区域合法性验证，失败则回退 |
| 多区域共享边界 | 出现裂缝或重复面 | 冲突图和统一源快照提交 |
| UV 跨岛重建 | 纹理拉伸 | Seam 作为约束，严格模式下拒绝跨接 |
| Decimate 仍删除重要边 | 轮廓破坏 | 应用后做特征位移检查，必要时回退 |
| Shape Keys 无法映射 | 动画或变形损坏 | 默认拒绝自动重拓扑，后续单独支持 |
| 大网格计算过慢 | Blender 卡顿 | 缓存、分帧、局部处理和取消 |
| GN 合并造成不可预期拓扑 | 结果质量不稳定 | 明确定位为快速预览，并提供保守上限 |
| 自动结果过于激进 | 用户不敢使用 | 预览、失败报告、撤销和默认保守参数 |

## 21. 初始默认策略

第一版建议采用以下默认值和行为：

- 默认使用物体形状模式。
- 默认保护边界、非流形边、Sharp、Crease 和 UV 边界。
- 默认不处理含 Shape Keys 的对象。
- 默认只处理通过区域验证的面带。
- 默认允许失败区域保持原状，不自动强制修复。
- 默认保留现有 Decimate 作为剩余区域的回退。
- 默认先预览，再应用。
- 默认生成详细结果报告。

## 22. 验收标准

功能达到可进入正式使用前，至少满足：

1. 不修改分析模式下的原始网格。
2. 所有预览都可以取消并恢复到进入前状态。
3. 单区域重建不产生重复边、零面积面和明显裂缝。
4. UV、材质、Seam、Sharp 和平滑标记在支持范围内正确保留。
5. 主要特征边的最大位移和相机轮廓误差可测量。
6. 失败区域不会静默丢失，结果面板会说明原因。
7. 多区域处理不会依赖前一个区域重建后的索引。
8. 对不支持的网格类型能够安全回退。
9. LOD 相机变化能够影响目标密度，但不会删除保护边链。
10. 现有 LODify 的原始 Decimate、Geometry Nodes、Reset 和 Apply 流程继续可用。

## 23. 待决策项

正式开发前需要确定：

1. 第一版是否只支持四边面为主的网格。
2. 是否把自动特征边链展示为必须人工确认的候选结果。
3. 相机模式是否只使用一个 LOD 相机，还是支持当前视口。
4. 失败区域默认保持原状，还是允许自动使用 Decimate。
5. 是否把 Shape Keys 和骨骼权重排除在第一版之外。
6. 是否需要生成独立的低模对象，还是直接修改原对象的非破坏性修改器。
7. Geometry Nodes 合并模式是否继续保留，或改名为快速距离合并模式。
8. 是否需要把 Loop Resample 的局部手动调整交互直接集成到 LODify。
9. 是否需要在后续阶段接入 QuadriFlow 作为完整重拓扑后端。

## 24. 推荐的开发顺序

推荐先完成“分析模式 + 单区域引导式重采样 + 可靠回退”，再接入批量多区域和相机 LOD。这样可以尽早验证自动边链是否真的能找到有意义的形状特征，也能在不破坏现有 LODify 工作流的情况下逐步积累质量数据。
